# Web Optimization Skill
用于新建或改造前端网页时，把体验优化落成可验证的工程步骤。
## 工作方式
1. 先确认入口、静态资源、运行脚本和部署环境。
2. 减少首屏阻塞，重型模型按需加载。
3. 明确加载中、权限拒绝、不支持和失败降级状态。
4. 使用稳定的响应式尺寸，防止布局跳动和移动端横向滚动。
5. 对 Canvas/WebGL 限制 DPR、对象数量和每帧工作量，并支持 reduced-motion。
6. 控件使用语义元素、焦点样式和可访问标签。
## 验收清单
- 桌面与窄屏首屏无裁切、重叠或横向滚动。
- 无摄像头、拒绝权限、模型失败时仍能完成预览。
- 控件有真实状态变化，提示使用 aria-live 或对话框语义。
- 控制台无未处理错误；第三方失败有降级路径。
- Playwright 检查非空、主要按钮、风格切换和移动视口。
